# How to run our program
**To run our program, simply "Run All" in run_experiments.ipynb**

## Structure
*decision_tree.py*: Contains our DecisionTree class and our Node class.
*permutation_importance.py*: Contains our permutation importance function.
*synthetic_dataset.py*: Contains our function for creating a synthetic dataset, used only for testing.
**run_experiments.ipynb**: Main notebook which implements all part of our program.
